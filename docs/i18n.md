# App 多语言

App 界面支持中文（`zh`）、英文（`en`）和越南语（`vi`）。未选择时默认中文；登录页和任务列表的用户抽屉都能切换语言。语言保存在 SQLite 的 `qcm_language` 设置中，启动时恢复，同一个值也用于 API 的 `Accept-Language` 请求头和 `language` 查询参数。

界面组件从 `i18n/index.uts` 导入 `t`，用中文源文案作为键；例如 `t('已选 {count} 条', { count: count })`。动态 UI 状态和服务返回的中文提示也应在展示时翻译，不要翻译存入数据库的用户输入、业务 ID 或枚举值。英文、越南语词条位于 `i18n/translate.uts`；已有 H5 词条沿用同项目的词典，App 专属文案放在 `appCopy` 中。缺失词条回退中文，新增界面文案必须同时补齐英越翻译和测试。

调试页不属于正式验货流程。运行 `npm test` 可检查界面静态文案、词条、最终提交规则和现有业务测试。Android/iOS 的原生构建还需在 HBuilderX 中分别验证。
