# App 首页与 H5 列表对齐设计

## 目标

修复 App 首页云同步入口持续同步的问题，并将顶部云图标、右下角浮动操作、卡片下载/合并/更多图标和卡片操作菜单对齐 H5。列表页保持 H5 的状态与操作判断，进入验货详情后仍以 App 离线拍照和本地编辑能力为主。

## 边界

- 对齐：顶部栏、状态页签、计划分组、卡片状态、下载状态、浮动菜单、卡片更多菜单和离线同步状态。
- 保留：App 当前本地优先列表、计划下载、本地状态修改和离线数据库。
- 不照搬：H5 的 DOM、浏览器下载、钉钉 JSAPI、调试面板和仅浏览器可用的交互。
- 暂不扩展：完整验货详情、报告导出、复杂合并结果编辑和照片上传流程。

## 同步状态机

云图标不再绑定“刷新远程列表”。点击后由页面调用独立同步方法：

1. 若正在同步，直接返回，防止重复任务。
2. 重新统计本地 `DIRTY` 或带 `pendingSyncPayload` 的计划。
3. 无待同步数据时结束并提示“本地数据已是最新”。
4. 离线时结束并提示网络不可用。
5. 有待同步数据时执行一次同步任务；无可执行同步服务时保持待同步状态，不循环刷新列表。
6. 同步结束后刷新本地概览并清除 `isSyncing`。

同步卡片仅在存在待同步项或正在同步时展开，并自动收起；组件只发出 `sync-request`，不自行触发列表刷新。

## 组件拆分

- `components/icons/AppIcon.uvue`：统一云、下载、锁、合并、更多、搜索、扫码、加号等图标。
- `components/common/BottomActionSheet.uvue`：复用 H5 风格底部操作菜单。
- `components/sync/OfflineSyncStatus.uvue`：只负责云图标、徽标和同步提示卡。
- `components/inspection/InspectionPlanCard.uvue`：负责卡片视觉和根据状态生成操作项。
- `domain/listActionViewModel.uts`：纯函数计算 FAB 操作、下载状态和卡片操作，便于测试。

## 操作对齐

右下角按钮在“已定计划”和“报告”页签显示。已定计划菜单依次提供合并验货、扫码搜索、开始验货、创建快速验货；报告页签只保留扫码搜索和开始验货。当前 App 尚未完成的操作使用明确提示，不伪造成功结果。

卡片更多菜单按 H5 状态展示下载、查看当前验货员、解锁、重置、复制当前验货、复制合并验货、设置备货数量、显示报告和拆分验货。首期只执行 App 已具备的下载、本地重置、查看锁定验货员和详情导航；其余入口保持与 H5 一致并给出待接入提示。

## 验证

- 纯函数测试覆盖同步防重入、无待同步、FAB 菜单和卡片操作可见性。
- 现有计划下载、列表合并、认证和数据库测试必须继续通过。
- 检查所有新增或修改方法均有方法注释。
